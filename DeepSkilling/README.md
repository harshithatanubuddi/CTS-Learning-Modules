# CTS Deep Skilling – .NET FSE

This folder contains the mandatory hands-on exercises and assessments completed as part of the **Cognizant (CTS) Digital Nurture Deep Skilling Program – .NET Full Stack Engineer (FSE)** track.

The exercises are organized week-wise and cover core concepts including Design Principles and Patterns, Data Structures and Algorithms, Advanced SQL, NUnit and Moq, Entity Framework Core, ASP.NET Core Web API, Microservices, React, Git, Angular, and assessments.
